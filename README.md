# Custom MCP & KoboldCPP Integration Server

A lightweight and robust Python-based Model Context Protocol (MCP) and integration server designed to bridge local LLM runners (like KoboldCPP) with local workspace management and automation workflows.

---

## 🚀 Features (المميزات الرئيسية)
- **Local Workspace Management:** Securely list, read, and manage workspace files within designated directories (e.g., `E:\AI_Workspace`).
- **KoboldCPP Integration:** Built to seamlessly interact with local LLM setups, ensuring complete privacy and high-speed execution.
- **Developer-Friendly:** Clean and extensible Python code structured for rapid deployment and custom tool additions.
